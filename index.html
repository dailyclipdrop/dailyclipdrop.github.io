Daily Clip Drop

YouTube channel: @dcd_media

Daily Clip Drop publishes short gaming clips (YouTube Shorts) made from livestreams whose creators run official clipping campaigns that authorise this use.

DCD Clips (the app)

DCD Clips is a private tool used only by the channel owner. It connects to the owner's own YouTube channel through the YouTube Data API to upload the Shorts the owner prepares, add them to the channel's playlists, and check that an upload is public. It is not offered to other users.

YouTube API Services

DCD Clips uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Our Privacy Policy explains how YouTube data is accessed, used, stored and deleted, and links to the Google Privacy Policy.
